# security-hygiene-drill
Quarter-end security hygiene drill demo

## About this drill

This repository is a self-contained demonstration of a clean repo-hygiene workflow for the quarter-end security review.

- A `SECURITY.md` policy at the repository root
- A security checklist under `docs/security-checklist.md`
- A pull request proposing these changes for review, with branch protection and security tooling checks applied
